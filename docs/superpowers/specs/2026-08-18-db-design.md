## B1. 设计

### 1.1 目标

实现 `src/ai_github_radar/db/` 子包：
- `__init__.py` — 暴露 `Base` / `get_engine` / `get_session` / `init_db`
- `models.py` — 4 张 ORM 表：`Star` / `Keyword` / `TrendingSnapshot` / `Recommendation`
- `session.py` — engine 工厂 + Session 上下文管理器 + init_db helper

### 1.2 非目标

- ❌ Alembic 迁移（首次 release 用 `Base.metadata.create_all()` 即可，见 docs/database-design.md §ORM）
- ❌ 异步 engine（阶段一同步即可）
- ❌ 连接池配置（SQLite 单文件无需 pool）
- ❌ 任何业务逻辑（CRUD 由 T004+ 提供）

### 1.3 字段映射（按 docs/database-design.md DDL）

**Star** (`stars` 表)
- id / repo_id (UNIQUE) / owner / name / full_name / description / language / topics (JSON str) / homepage / stargazers_count / pushed_at / starred_at / fetched_at / archived (bool)
- 索引：language / fetched_at

**Keyword** (`keywords` 表)
- id / term (UNIQUE) / weight (default 1.0) / source ("auto"|"manual") / enabled (bool default True) / created_at / updated_at
- 索引：enabled

**TrendingSnapshot** (`trending_snapshots` 表)
- id / repo_id / snapshot_date / rank / stars_today / language / description / fetched_at
- UNIQUE(repo_id, snapshot_date)
- 索引：snapshot_date

**Recommendation** (`recommendations` 表)
- id / repo_id / score / matched_keywords (JSON str) / channel / pushed_at
- UNIQUE(repo_id, pushed_at)
- 索引：pushed_at / repo_id

### 1.5 路径解析

`load_settings().db_url` 形如 `sqlite:///./data/radar.db`。
SQLAlchemy `create_engine("sqlite:///./data/radar.db")` 会自动创建目录,所以
`init_db()` 调用前不需要手动建 `data/`。

## B2. 验收（AC-N）

| AC | 断言 | 怎么验 |
|---|---|---|
| AC-1 | `init_db(engine)` 跑通且 4 张表存在 | `sqlite3 data/radar.db ".tables"` → stars / keywords / trending_snapshots / recommendations |
| AC-2 | `get_engine()` 不带参数时从 `RADAR_DB_PATH` 读 | 单测：monkeypatch RADAR_DB_PATH → engine.url.database == 设置值 |

| AC-8 | Recommendation (repo_id, pushed_at) UNIQUE | 单测：同上 |

## B4. 风险

- **R1**：SQLAlchemy 2.0 与 1.x 风格 API 差异巨大。**缓解**：严格用 2.0 风格（`DeclarativeBase` / `mapped_column` / `Mapped[...]`）。
- **R2**：宿主机 Python 3.9,pyproject 标 requires-python = ">=3.12"。SQLAlchemy 2.0 需 py3.7+,但 `Mapped[...]` 注解需要 3.9+ typing。**缓解**：用 `Mapped[...]` 而非新 PEP 695 语法。
- **R3**：SQLite 默认不允许并发写。**缓解**：阶段一单人单机 + 串行 init/scan,无并发问题。
- **R4**：`data/` 目录默认创建,但 .gitignore 已经忽略。**缓解**：在 db/__init__.py docstring 提示用户,无需额外配置。
